# 📝 To-Do App

A simple To-Do application built with **HTML**, **CSS**, and **JavaScript**. The app lets you add and delete tasks, with the tasks being stored in **local storage** so they persist across page refreshes.

## ✨ Features
- **➕ Add Task:** Easily add new tasks.
- **❌ Delete Task:** Remove tasks from your list.
- **💾 Persistent Data:** Tasks are saved in **local storage** and will remain even after page refresh.


## 💻 Technologies Used
- **HTML**: Markup for the app structure.
- **CSS**: Styling the app with a clean, user-friendly design.
- **JavaScript**: Implements task management features and local storage functionality.
